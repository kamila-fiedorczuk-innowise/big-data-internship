# Task 06 - PySpark (ZillaCode)

## Task description

Solutions to ZillaCode challenges written in PySpark: 10 easy problems
and all medium and hard problems.

ZillaCode is an open-source platform with LeetCode-style data engineering
problems. It runs locally with Docker Compose, and each solution is tested
there against the expected output.

## Setup

The local venv (`requirements.txt`) is only for code completion in the IDE.
The code runs in the ZillaCode Spark container.

## Solutions

Each file in `solutions/` contains the `etl` function for one problem
and passed the ZillaCode tests.
